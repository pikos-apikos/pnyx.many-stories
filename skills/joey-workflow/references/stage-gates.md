# Joey Workflow Stage Gates

| Current stage | Required approved dependencies | Unlocks |
|---|---|---|
| Story bible | Destination | Character specifications, locations, story engines |
| Character text lock | Story bible | Face lock |
| Face lock | Character text lock | Base outfit |
| Base outfit | Face lock | Character sheet, scene wardrobe reference |
| Character sheet | Face lock + base outfit | Reliable multi-angle continuity |
| Prop | Story bible or scene requirement | Scene plate |
| Empty environment | Story bible + location spec | Scene plate |
| Scene plate | Character/outfit + required prop + environment | Video prompt |
| Video prompt | Approved scene logic | Render candidates |
| Edit | Approved takes + audio plan | Final production |

A later stage may begin without an optional asset only when the Production Map explicitly records why it is not a dependency.
